# Runtime Components

These are the personal configuration files for the command line.

- ".bashrc" - Sets up your bash. Shows your prompt and command shortcuts.
- ".zshrc" - Same thing as bash but for zsh
- ".vimrc" - You get the vim editor. You get line numbers and you get customize your behavior like indentation.
- ".gdbinit" - Sets up GDB. You can inspect and analyze the execution of other programs.
- ".gitconfig" - Sets up Git. Control how git looks like and works.
